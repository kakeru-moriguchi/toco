# 大会リハーサル結果（2026-11-26）

## 結果と範囲

35チーム・3部門の使い捨てローカルDBで、予選70試合と決勝本戦23試合、単発敗者戦7試合の計100試合を結果承認まで進行できた。本番Supabase、登録済みチーム、配布用PINには変更を加えていない。DBマイグレーションは不要。今回の変更は本番未反映。

これは大会形式とデータ処理の完走確認であり、PDFの時刻・コートを全行再現した確認ではない。後述の時間割調整が必要。

追試：[PDFの固定時刻・コート共用の検証](TOCO_TIMETABLE_CHECK.md)。主催者が承認した表記整理を反映し、予選70枠と決勝24枠を保存できた。15:45開始の6枠は試合時間が未確定のため保留。以下の18:45という時刻は、当初の固定コート構成の結果であり、PDFの時間割に当てはめた終了時刻ではない。

## 自動検証

- 初中級20チーム：4リーグ各5チームの総当たり40試合、順位別4チームトーナメント5級・本戦15試合・単発敗者戦5試合。
- 中上級10チーム：2リーグ各5チームの総当たり20試合、上位4チーム・下位6チームの本戦計8試合・単発敗者戦2試合。予選1位へのBYEとリーグをまたぐ初戦を既存の純粋関数テストでも確認。
- 50歳以上5チーム：総当たり10試合。決勝作成の呼び出しは具体的なエラーで拒否。
- 勝者のPINによる仮送信、自己承認の拒否、敗者による差し戻し、修正再送信、敗者承認。仮結果は正式順位に反映されない。
- 管理者未認証の設定変更は401、認証済みでは選択部門のリーグ数だけを変更。他部門の設定・チーム・試合が変わらない。
- 結果更新が他部門の試合を変更しない。
- 8面全体のコートとチームの時間重複がない。30分・45分の異なる長さ、13:00〜13:30の休憩を考慮。
- 勝者・敗者の進出先は前の試合終了後に配置。単発敗者戦を含む再割り当て後も依存関係と重複を再検査。
- BYEを除く最初の実試合で敗退したチームだけが単発敗者戦へ進む。重複生成や2試合目の参加がない。
- 下位6チームのBYE通過者が初戦で敗退するケースを含む。対象3チームになった時点では自動生成せず、管理者が2チームを指定して1試合を作成。残り1チームは未割当のまま主催者判断とし、自動BYEを付けない。
- 単発敗者戦生成後の本戦訂正は、先に敗者戦を取り消す案内を返す。
- 匿名ロールにチームPINテーブルの参照権限と敗者戦生成RPCの実行権限がない。

DB検証にはPGliteのPostgreSQLエンジンを使用。実際の `supabase/schema.sql`、SQL 011のDB関数、アプリのデータ関数、設定保存APIを実行する。UUID生成に不要なpgcrypto拡張の作成だけを省略している。ローカルHTTPアダプターは必要なPostgREST構文だけを実装しており、Supabaseサービス自体の互換性・Realtime・複数DBセッションの競合制御まで保証するものではない。既存の承認フローテストには同時承認のケースがあるが、本番の分散負荷試験ではない。

## ブラウザ検証

ローカル画面（35チームの専用データ、3ゲーム制）で次を手動確認した。

- 結果入力画面で差し戻し→点数修正→再送信→敗者承認→再読込後の確定結果表示。
- 承認待ちと確定後の表示切り替え、3ゲームすべての点数表示。
- 管理画面へのログイン後、大会・部門の選択UIが表示される。
- 同一オリジンの管理者画面で部門を変えても、参加者側の選択部門は変わらず、再読込でも維持される。
- 390px相当の画面で、長い日本語チーム名を含む結果入力画面と部門設定フォームにページ全体の横はみ出しがない。

この画面確認は手動操作であり、自動ブラウザテストとして保存していない。

## 発見した原因と修正

| 問題 | 根本原因 | 修正 |
| --- | --- | --- |
| 決勝・3位決定戦が準決勝と同時刻になる | 未定チームは同一チーム検査で拾えず、進出元の試合終了時刻も参照していなかった | 勝者・敗者の進出先の依存関係を自動割り当てと手動編集・並べ替えで検査 |
| 単発敗者戦が夜遅くまで延びる | 大会全体の最終予定時刻より後へ、級ごとに追加していた | 対象級の全員の初戦終了後の空き枠へ配置。既存試合・他部門・休憩を維持して重複回避 |
| 初回ログイン後に部門選択が出ない | 大会選択が別のフックから保存された際、保存値が有効なら画面の大会IDを更新しなかった | 有効な保存値も画面の大会IDへ必ず反映 |

## 時間割に残る調整

自動テストは初中級1〜4面、中上級5〜6面、50歳以上7〜8面の固定コートで各部門を09:00開始としている。PDFの時間帯別運用そのものではない。

| 部門 | 予選開始〜終了 | 決勝・単発敗者戦開始〜終了 |
| --- | --- | --- |
| 初中級 | 09:00〜14:30 | 15:00〜18:45 |
| 中上級 | 09:00〜14:30 | 15:00〜18:45 |
| 50歳以上 | 09:00〜11:30 | なし |

初中級40試合を30分・固定4面で実施すると、最低でも300分のコート時間が必要。PDFのコート共有と50歳以上の遅い開始を反映せず、コート数と開始時刻だけを設定しても、同じ時間割にはならない。今回の修正で敗者戦の不要な繰り延べは解消したが、固定コート方式の容量制約は残る。

本番利用前に、PDFに合わせて進行表の時刻・コートを手動設定し、全体の重複と終了時刻を確認する必要がある。時間帯別のコート使用ルールを自動生成に組み込む場合は別途実装が必要。PDFのリーグ・対戦番号の表記整理、11:30のF7、16:00の下位決勝1試合化は主催者承認済み。15:45枠の試合時間は未確定。PDF原本は変更していない。
