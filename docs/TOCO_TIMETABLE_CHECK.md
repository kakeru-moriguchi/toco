# PDFの固定時刻・コート共用の検証（2026-11-26）

## 結果

`【完】試合進行表.pdf` の色分けと対戦カードを基準に、既存の管理用保存APIで時間割を保存・再取得した。本番用プリセットの追加や本番データの更新は行っていない。

- 予選70試合：全枠を保存できた。初中級と中上級オープンは13:00までに終了し、50歳以上は12:00開始で他部門の決勝と並行進行する。
- 決勝本戦・単発敗者戦30試合のうち24枠：保存できた。確定した枠は16:45までに終了する。
- 残り6枠：15:45開始の試合時間が未確定。勝手に15分へ短縮せず、検証用DBでも時刻を未設定のまま残した。
- 45分を一律適用して全枠を保存しようとすると、時刻の重複または進出元より早い次戦として拒否され、途中の行だけ保存されることもなかった。
- 大会全体がこの時間割で完了できるかの判定は、6枠の時間が決まるまで保留。

各試合の結果を承認まで進める完走試験は先に別の時間割で実施済み。この固定時刻試験は、その100試合に対して時刻・コートを付け直して検証する。両者を混同して「PDF通りの大会を完走済み」とは扱わない。

## 主催者が確定した扱い

- 色分け・対戦カードを優先し、番号とリーグ表記を整理する。緑はEリーグ、青はFリーグ。A・C・G等の試合番号は、凡例の対戦順に合わせて振り直す。
- 11:30・5コートは、重複していたEの「2対4」ではなく、欠落していたFの「2対4」（F7）とする。
- 16:00の中上級下位決勝は7コートの1試合とし、8コートは予備枠とする。3位決定戦は追加しない。
- 開始時刻はPDFのまま。15:45の1〜6コートの試合時間は後日決定する。

## 今回追加した不具合修正

既存試合を新しいコートへ移動した際、休憩枠の検証対象コートが変更前の一覧だけだったため、未使用コートなら全館休憩へ移動できた。変更後のコートも含めて休憩枠を展開するよう修正し、13:10開始への移動が拒否される結合テストを追加した。

時刻の重複エラーには、問題となる開始時刻・コートを表示する。進出元の終了待ちが必要な場合も、前後の時刻・コートと調整方法を案内する。

DB変更なし。UIの配色・レイアウト変更なし。対象は `toco` のみ。
