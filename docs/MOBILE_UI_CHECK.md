# 管理画面のスマホ表示修正（2026-11-28）

## 原因と修正

- 上部メニュー：各ページに置かれたAdminShellがページ移動時に再作成され、横スクロールが先頭へ戻っていた。横位置をタブごとのsessionStorageへ保存し、再作成時にuseLayoutEffectで復元する。スクロールとリンクのクリック時に記録する。ストレージが使えない場合もページ移動は妨げない。
- 読み込み前後の幅：縦スクロールバーの有無で横スクロールの最大値が変わり、保存位置が15px切り詰められるケースがあった。htmlにscrollbar-gutter: stableを指定し、幅を安定させる。
- 「大会形式を設定」：外側に描画されるringが、親要素のoverflow-hiddenで欠けていた。ボタンのringを内側へ描画するようにし、フォーカス表示も内側へ収める。タップ領域を48pxにし、開閉状態をaria-expandedで伝える。
